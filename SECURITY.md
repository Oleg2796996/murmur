# Security Policy

## Scope

MurMur is experimental software. It has not undergone an independent security audit. Please review the code and threat model before using it for sensitive or high-risk communications.

## Reporting a vulnerability

Please do **not** disclose suspected vulnerabilities in a public GitHub issue.

Until a dedicated private vulnerability-reporting channel is configured, report security issues privately to the maintainer through the contact method listed on the [MurMur website](https://murmurchat.org/). Include:

- a clear description of the issue;
- affected component and version or commit;
- reproducible steps or proof of concept, if safe to share;
- potential impact.

Please allow reasonable time for investigation and coordinated disclosure. Do not include real users' private messages, private keys, or other sensitive data in a report.

## Supported versions

There are currently no stable releases. The `main` branch is the active development version.
